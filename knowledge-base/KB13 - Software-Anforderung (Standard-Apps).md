Hinweis zum Prozess:
Interne Anfragen sind grundsätzlich gemäß KB07 über den Service Desk aufzunehmen und zu steuern. Erst nach Prüfung und Vollständigkeitskontrolle erfolgt die Weiterleitung an die zuständige Fach- oder Supportgruppe.
Externe Supportanfragen können – sofern die Voraussetzungen erfüllt sind – direkt über definierte Vorlagen, Keywords oder Trigger verarbeitet werden.

KB13 – Software-Anforderung (Standard-Apps)

Problembeschreibung

Mitarbeitende oder Fachbereiche benötigen eine zusätzliche, im Unternehmen freigegebene Standard-Software (z. B. PDF-Editor, Projektmanagement-Tool oder Fachanwendung), die auf ihrem Client-System installiert werden muss.
Typische Ursachen / Einordnung
•	Aufgabenerweiterung: Ein Mitarbeiter hat neue Tätigkeitsbereiche übernommen, die spezielle Software-Werkzeuge erfordern.
•	Fehlende Berechtigungen: Anwender verfügen nicht über die notwendigen lokalen Administratorrechte, um Installationen eigenständig durchzuführen (Sicherheitsrichtlinie).
•	Lizenzmanagement: Für die Nutzung der Software muss vorab eine kostenpflichtige Lizenz zugewiesen oder freigegeben werden.
Prüfschritte Service Desk
1.	Eingang der Anforderung prüfen und auf Vollständigkeit der Pflichtangaben kontrollieren.
2.	Prüfen, ob eine gültige Vorlage genutzt wurde oder ob es sich um eine interne Anfrage handelt.
3.	Validieren, ob die Vorgaben gemäß KB07 eingehalten wurden (Eindeutige Titelzeile, Beschreibung mit Anforderer, betroffener Benutzer, genauer Name der benötigten Software und – ganz wichtig – die dokumentierte Freigabe/Kostenstelle des Vorgesetzten).
4.	Keine eigene Installation oder Software-Zuweisung durch den Service Desk; das Ticket wird direkt an die zuständige Supportgruppe (Client-Management / Software-Verteilung) übergeben.
Technische Prüfung und Bereitstellung (Client-Management)
1.	Prüfung, ob die angeforderte Software Teil des offiziell freigegebenen Unternehmens-Portfolios ist.
2.	Kontrolle der verfügbaren Lizenzen und Verbuchung der Zuweisung an den entsprechenden Benutzer.
3.	Automatisiertes Ausrollen der Software über das zentrale Management-System (z. B. SCCM, Intune) oder Installation via Remote-Support.
4.	Kurze Rückmeldung an den Anwender nach erfolgreichem Deployment zur Bestätigung der Funktion.
Weiterleitung / Ticket-Routing
•	Titelformat: IT-Support Service Desk - Softwarebereitstellung
•	Zielgruppe: Client-Management / Applikations-Support
